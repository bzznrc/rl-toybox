# Assets

Shared runtime assets for the repo.

Suggested layout:

- `assets/fonts/` for `.ttf` and `.otf`
- `assets/audio/` for `.wav`, `.ogg`, `.mp3`
- `assets/icons/` for `.ico`, `.png`, `.svg`

Notes:

- Gameplay/demo media stays in `media/`
- Game code should resolve shared runtime assets through `assets.paths`
